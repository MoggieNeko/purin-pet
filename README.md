# Purin Pet

一個為手機而設、原創布甸小狗風格嘅虛擬寵物 PWA。第一次打開可以幫小狗改名，之後餵食、沖涼、玩耍、瞓覺，進度會自動留喺裝置。

## 已有功能

- 四項會隨時間下降嘅照顧數值
- 全新分層式 SVG 角色模組，服裝與前肢分層避免穿模
- 數值會直接改變角色表情、動作、污漬、眼淚及精神狀態
- 餵食、沖涼、玩耍、瞓覺冷卻、需要判定及動態獎勵
- 等級、經驗值、金幣、羈絆、每日禮物與連續見面日數
- 10 秒「接布甸」小遊戲，設有點擊節流及獎勵上限
- 10 套可解鎖服裝與 7 個可解鎖生活場景
- 有兩個選項及不同結果嘅隨機突發事件
- Lv.18、14 日陪伴後開放嘅後期家庭與小寶寶系統
- 成長日記會記錄照顧、事件、解鎖及家庭里程碑
- 自訂小狗名及每日小紙條
- 聲效、低狀態通知、進度匯出／匯入
- 離線快取及「加入手機主畫面」
- GitHub Pages 自動部署

## 本機試玩

```bash
npm install
npm run dev
```

## 發佈到 GitHub Pages

1. 把整個專案推送到 GitHub repository 嘅 `main` branch。
2. 去 repository `Settings` → `Pages`。
3. 將 `Source` 設定為 `GitHub Actions`。
4. `Deploy Purin Pet to GitHub Pages` 完成後，GitHub 會顯示公開網址。

之後每次推送到 `main`，都會自動更新。
