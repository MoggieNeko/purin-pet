# Purin Pet

一個同時為手機同電腦而設、原創布甸小狗風格嘅虛擬寵物 PWA。第一次打開可以幫小狗改名，之後餵食、沖涼、玩耍、瞓覺，進度會自動留喺裝置。

## 已有功能

- 四項會隨時間下降嘅照顧數值
- 單次高解像度 Canvas 角色渲染：每一幀只畫一個完整角色，完全移除會在 Safari 疊影、穿模及頸位分離嘅多層 CSS 骨架
- 高 DPI、透明 WebP 圖集、柔邊縮放與影像平滑，手機同電腦會共用同一套像素渲染流程
- 連身高解像度動作圖集：躺平、自娛玩具、睡眠、進食、沖涼、跳躍等姿勢唔再拆開頭身
- 自動呼吸、側頭、嗅聞、搖擺、躺平、自娛同小睡待機動作，輕按角色仲會開心彈跳
- 數值高低會直接切換跳舞、慢呼吸、肚餓縮身、孤單垂頭、抓癢、睏倦或虛弱動作
- 餵食、沖涼、玩耍、瞓覺改為 6–8 秒可觀看動作，並保留冷卻、需要判定及動態獎勵
- 等級、經驗值、金幣、羈絆、每日禮物與連續見面日數
- 24 秒「甜品接接樂」拖曳小遊戲，有布甸、士多啤梨、星星、障礙、生命、Combo、FEVER 雙倍分及獎勵上限
- 16 套可解鎖服裝與 12 個可解鎖生活場景
- 12 幅獨立精緻 3D 場景插畫，配合視差、光影、景深同主題粒子
- 電腦版自動使用寬屏雙欄版面；「桌寵」模式可以全畫面漫遊、拖曳角色、摸摸互動及按 Esc 返回
- 香蕉、布甸杯、蝦壽司、紙皮飛碟等搞怪服裝
- 巨型布甸星球、反轉傢俬房、復古機舖等特殊場景
- 幼年、青年、壯年、中年、老年五種明顯不同可愛身形，成長頁可以預覽一生變化；解鎖要同時達到等級同真實陪伴日數
- 有兩個選項及不同結果嘅隨機突發事件
- Lv.18、14 日陪伴後開放嘅後期家庭與小寶寶系統
- 成長日記會記錄照顧、事件、解鎖及家庭里程碑
- 自訂小狗名及每日小紙條
- 聲效、低狀態通知、進度匯出／匯入
- 離線快取及「加入手機主畫面」
- GitHub Pages 自動部署

## 本機試玩

```bash
npm install
npm run dev
```

## 發佈到 GitHub Pages

1. 把整個專案推送到 GitHub repository 嘅 `main` branch。
2. 去 repository `Settings` → `Pages`。
3. 將 `Source` 設定為 `GitHub Actions`。
4. `Deploy Purin Pet to GitHub Pages` 完成後，GitHub 會顯示公開網址。

之後每次推送到 `main`，都會自動更新。
