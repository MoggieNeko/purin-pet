# Purin Pet

一個同時為手機同電腦而設、原創布甸小狗風格嘅虛擬寵物 PWA。第一次打開可以幫小狗改名，之後餵食、沖涼、玩耍、瞓覺，進度會自動留喺裝置。

## 已有功能

- 四項會隨時間下降嘅照顧數值
- 高解像度角色合成會由五套年齡專屬 4×4 服裝圖集直接抽取完整造型，再連同場景色調烘焙成單一紋理；頸、頭同身體保持連接，亦唔會出現切片格仔
- 柔性網格使用同 Canvas 一致嘅左上原點貼圖座標，避免手機 WebGL 重複反轉角色；靜態縮圖同動態角色方向保持一致
- 高 DPI、透明 PNG 年齡底模、柔邊縮放與影像平滑，手機同電腦會共用同一套單畫布渲染流程
- 五個年齡階段各自使用獨立透明角色圖：幼年有奶嘴及寶寶比例、青年輕巧有活力、壯年係經典巔峰造型、中年厚實兼戴幼框眼鏡、老年有白眉毛、圓眼鏡及小手杖；唔再用切片網格、拉長或壓扁同一張圖
- 年齡會實際改變飽肚、開心、乾淨、精神嘅自然下降速度，以及照顧回復、活動消耗、冷卻、經驗同羈絆倍率
- 所有互動都保留當前年齡底模；柔性網格加入頭、耳、手、腳嘅關節軸心與局部旋轉，進食、沖涼、玩耍、睡眠同待機唔再靠拉伸整張角色圖
- 16 套服裝均為五個年齡獨立繪製嘅完整角色造型，共 80 個高質透明版本；手腳、耳仔、臉、眼鏡、奶嘴及老年手杖唔再由程式幾何圖形硬套
- 每款衣服都有真正衣料厚度、縫線、鈕扣、褶位、帽沿、配件遮擋同年齡專屬剪裁，衣櫃縮圖與主畫面共用同一個成品來源
- 互動畫面使用獨立高質透明道具圖集：熱布甸碗、泡泡鴨仔、縫線玩具球、月亮被鋪、絲帶禮物盒、慶祝星光、思考泡泡同嬰兒搖籃，取代簡陋幾何圖形
- 單畫布動作過場：320ms 收勢回到中立姿勢、切換動作，再用 760ms 逐個關節柔和展開；道具與舞台光亦同步淡出淡入，完全移除舊式雙影淡入造成嘅點擊虛化
- 自動呼吸、側頭、嗅聞、搖擺、躺平、自娛同小睡待機動作；輕按角色只會在實際觸碰位置出現一個柔和光圈同星光
- 待機改用「休息—起勢—動作—回位」時間線，動作之間保留停頓；走路使用連續落腳曲線及細幅重心轉移，移除絕對值尖角彈跳同兩格陰影閃動
- 數值高低會直接切換跳舞、慢呼吸、肚餓縮身、孤單垂頭、抓癢、睏倦或虛弱動作
- 餵食、沖涼、玩耍、瞓覺改為 6–8 秒可觀看動作，並保留冷卻、需要判定及動態獎勵
- 等級、經驗值、金幣、羈絆、每日禮物與連續見面日數
- 24 秒「甜品接接樂」拖曳小遊戲，有布甸、士多啤梨、星星、障礙、生命、Combo、FEVER 雙倍分及獎勵上限；掉落物加入深色底、白邊、彩色光圈及分數標籤，首波會即時出現在畫面
- 16 套可解鎖服裝與 12 個可解鎖生活場景
- 8 個動漫 DLC 角色包：每個代碼會一次過解鎖該角色幼年、青年、壯年、中年、老年五套獨立剪裁造型，以及一個配套代表場景；兌換狀態會跟存檔匯出／匯入
- 12 幅獨立精緻 3D 場景插畫，配合視差、光影、景深、主題粒子，以及按場景轉色嘅角色邊光、地面反光同接觸陰影
- 電腦版自動使用寬屏雙欄版面；「桌寵」模式會按年齡以幼兒步、活力跑、穩定步、慢步或拐杖碎步漫遊，移動期間有腳步起伏、左右落腳、接觸陰影及方向轉身
- 香蕉、布甸杯、蝦壽司、紙皮飛碟等搞怪服裝
- 巨型布甸星球、反轉傢俬房、復古機舖等特殊場景
- 幼年、青年、壯年、中年、老年五種獨立身形輪廓，中年加入眼鏡、老年加入柔和口鼻色同手杖；手機成長預覽改為不變形橫向卡片，解鎖要同時達到等級同真實陪伴日數
- 有兩個選項及不同結果嘅隨機突發事件
- Lv.18、14 日陪伴後開放嘅後期家庭與小寶寶系統
- 成長日記會記錄照顧、事件、解鎖及家庭里程碑
- 自訂小狗名及每日小紙條
- 聲效、低狀態通知、進度匯出／匯入
- 離線快取及「加入手機主畫面」
- 手機設定／成長／衣櫃改為完整可視高度面板，內容獨立捲動，底部導覽固定佔位，避免 iPhone Safari 出現截斷、大片空白或導覽蓋住圖片
- GitHub Pages 自動部署

## 本機試玩

```bash
npm install
npm run dev
```

## 發佈到 GitHub Pages

1. 把整個專案推送到 GitHub repository 嘅 `main` branch。
2. 去 repository `Settings` → `Pages`。
3. 將 `Source` 設定為 `GitHub Actions`。
4. `Deploy Purin Pet to GitHub Pages` 完成後，GitHub 會顯示公開網址。

之後每次推送到 `main`，都會自動更新。
